# RockAutoMusicPlay

当前版本：**1.2.3**

Windows 九键音乐工作台：将 MIDI 转换为固定九音键谱，支持音符编辑、手碟试听、歌曲跟练、工程保存与 Interception 自动演奏。

## 快速开始

1. 从 [GitHub Releases](https://github.com/kanostars/Rock-auto-music-player/releases) 下载 Windows x64 便携版，完整解压后运行 `RockAutoMusicPlay.exe`，保留同目录 DLL 和插件文件夹。
2. 点击“导入 MIDI”，或将 MIDI 拖入窗口、拖到 EXE 上；支持批量追加。可先导入 `samples/studio-demo.mid` 体验。
3. 勾选参与转换的音轨，调整右侧参数后点击“应用设置 · 重新转换”。默认自动移调，并优先保留同音名、折叠八度；其余音符可近似转换或跳过。
4. 点击“手碟试听”听歌，或点击比例显示左侧的“跟练练习”。试听与跟练无需驱动；向游戏自动按键需要安装并启用 [Interception](https://github.com/oblitum/Interception) 驱动。

## 工作台

- 曲目库显示总数，支持排序、移除、上一首 / 下一首，以及单曲播放、顺序播放、单曲循环、随机播放。移除曲目不删除磁盘文件。
- 音符支持添加、框选、多选、移动、拉伸、升降音级、删除及撤销 / 重做。“转换报告”可查看原音与目标音，双击定位。试听暂停后可编辑，自动演奏会话期间锁定编辑。
- 滚轮横向移动，`Ctrl+滚轮` 缩放，“查看全部”适配整曲。“全屏轨道”放大编辑区，`F11` 切换全屏，`Esc` 返回工作台。
- 拖动绿色边界选择播放区间；可删除整段时间或插入等长空白，支持撤销。区间只限制播放范围，导出仍包含完整曲目。
- 工作台与跟练页可点击时间显示左侧输入 `01:30.50` 或 `90.5`，回车提交，`Esc` 取消；也可点击 / 拖动进度条定位。
- 导入时发现同键过密冲突，可选择跳过、删除或保留。保留冲突时须先调整按下时长、松开间隔或编辑音符，再开始试听 / 自动演奏。
- 自动演奏需在右侧手动刷新并选择输出键盘、目标窗口，再点击“开始演奏”。默认倒计时 5 秒；可选择启动时激活目标窗口。目标失焦时暂停，暂停或终止会释放按键。
- 点击左上角 Logo 或按 `F12` 切换置顶播放小窗，支持试听 / 自动演奏、切歌、曲目列表、进度与试听音量；可拖动位置、缩放并调整透明度。

## 导入与导出

右上角“工程”菜单读写 `.rockproj`，也可将工程拖入窗口或拖到 EXE 上。工程保存曲目、编辑与撤销记录、转换参数、播放位置及工作台布局；导入后保持暂停。

- 导出可选择“完整保存曲目数据”或“引用本地 MIDI 路径”，并逐曲指定来源文件。完整保存适合备份迁移；引用文件丢失时可重新选择 MIDI、跳过当前曲目或取消整次导入。
- 导入工程替换当前工作台；已有曲目时先确认。取消或读取失败保留原工作台。关闭程序时，未保存的工程调整会提示保存、放弃或取消。
- 工程默认名为 `project.rockproj`，首次导出目录为系统“文档”下的 `RockAutoMusicPlay/工程`；MIDI 为 `RockAutoMusicPlay/MIDI`。两者分别记住最近成功保存的目录。
- “导出 MIDI”保存当前曲目的完整九键转换结果，包含已应用的节奏参数及音符编辑，排除跳过 / 删除的音符与未启用音轨；内置采样音色不包含在 MIDI 中。
- “复制手弹谱”给出参考 BPM，按拍分组，每 4 拍换行。大写字母为按键，空格仅分组；`—` 表示本拍无新按键，`[BF]` 表示同时按下 B、F。
- “复制键谱”输出 `按键:拍数`，拍数为本次起点到下一组起点的间隔，末组延续至曲尾；曲首空白用 `—:拍数`。示例：

```text
# BPM: 120
H:0.75 H:0.25 J:1 H:1 T:1 K:2
```

两种文字谱均使用完整转换结果；右键对应复制按钮可导出 UTF-8 TXT。修改转换参数后，请先应用设置再导出或跟练。编辑不改写原始 MIDI，需导出 MIDI 或工程保存。

## 歌曲跟练

- 顶部可播放 / 暂停、重新开始、跳转时间、调节倍速与音量。“自动播放”预览歌曲；“跟弹练习”按当前组等待输入，按对后前进，和弦需同时按下，下一组前需松开。
- “时间轴”显示按键与音高，按小节划分，进入时默认 **75 px/s**。“简谱”按页浏览，使用八度点、减时线、附点、休止与延音连线；同音连线后段不重复敲击。
- 简谱跟随当前小节定位，小节内保持谱面位置。简谱模式下“下载简谱”左键保存本页 PNG，右键将全部页 PNG 打包为 ZIP。
- “练习设置 / 键位”合并弹窗支持 A/B 循环、节拍器、自定义九键及恢复默认；练习键位不改变工作台导出与自动演奏键位。
- 点击“小窗”或按 `F12` 进入游戏跟练小窗，可切换“当前按键胶囊”和“单小节简谱”。小窗提供进度、音量、透明度和大小调节，简谱随小节调整宽高；点击不抢占游戏焦点，跟弹默认静音，按键仍传递给游戏。
- 跟练页 `Esc` 返回工作台；完整页面失焦时暂停，小窗可在游戏前台继续跟练。

简谱按 1/16 网格量化排版，不改变实际播放时间。三连音、自由节奏等复杂节奏请结合试听校对。

## 设置与日志

- “测试按键”在设置页顶部，支持键盘 / 鼠标试听九键和弦，并查看本地按键日志。
- 浅色 / 深色主题即时生效；快捷键可修改、恢复默认并保存。演奏期间锁定快捷键和测试入口。
- Interception 状态卡自动检测，也可手动“重新检测”，显示连接状态、可用键盘数量及异常说明。演奏期间暂缓检测，检测与键盘刷新互斥。
- 设置页“返回工作台”左侧的“日志”实时显示关键操作与异常，可搜索、筛选等级、复制、导出 TXT、清空及打开日志目录。
- 日志保存于本机应用数据目录 `logs/app.log`，UTF-8 编码，每份约 2 MiB，最多保留 5 份；窗口保留当前会话最近 3000 条。

## 九键与常用快捷键

| 按键 | B | F | G | H | J | K | T | Y | U |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 音高 | A2 | E3 | F3 | G3 | A3 | B3 | C4 | D4 | E4 |
| 简谱 | 低 6 | 3 | 4 | 5 | 6 | 7 | 高 1 | 高 2 | 高 3 |

以下为默认快捷键，可在设置页重新绑定：

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+O` / `Ctrl+Shift+O` | 导入 MIDI / 工程 |
| `Ctrl+S` / `Ctrl+Shift+S` | 导出当前 MIDI / 工程 |
| `Space` | 试听或跟练播放 / 暂停 |
| `Ctrl+W` / `Ctrl+R` | 全局演奏暂停 / 继续、终止 |
| `Ctrl+Q` / `Ctrl+E` | 全局上一首 / 下一首 |
| `F12` | 全局主窗口 / 小窗切换（跟练中切换跟练小窗） |
| `Ctrl+Z` / `Ctrl+Y`、`Ctrl+Shift+Z` | 撤销 / 重做 |
| `Ctrl+A`、`Delete`、`↑` / `↓` | 全选、删除、升降音级 |
| `Alt+[` / `Alt+]` | 播放区间左 / 右边界移至播放标 |
| `F11` | 独立轨道全屏 / 还原 |
| `Esc` | 设置、全屏轨道、跟练返回工作台；弹窗先关闭 |

编辑快捷键在轨道区生效，输入框与快捷键录入保留正常输入。演奏暂停 / 终止组合只在演奏会话中注册。

## 构建与发布

需要 C++20 编译器、CMake ≥ 3.24、Qt ≥ 6.5（Widgets / Concurrent），编译器须与 Qt 工具链匹配。配置 Qt SDK 后构建：

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH="<Qt SDK 路径>" -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

使用 CLion 自带 MinGW / CMake，且 Qt 位于 `.deps/Qt` 时，可运行 `./scripts/build.ps1`。Windows 构建会自动部署运行库；运行时保留 EXE 同目录 DLL 和插件目录。手碟采样与图标已内嵌，无需单独安装音色库。

```powershell
./scripts/package-release.ps1            # 构建并打包
./scripts/package-release.ps1 -SkipBuild # 使用已有构建
```

发布包输出到 `artifacts/releases/`，包含运行依赖、示例曲目与许可文件。Qt SDK 与构建产物不提交到源码。

## 范围与许可

支持 SMF Format 0/1、PPQ、原曲变速、固定 BPM、中文路径与工程保存；不支持 Format 2、SMPTE、实时 MIDI、弯音 / 踏板效果或音频导出。自动演奏仅支持 Windows，程序不安装 Interception 驱动，游戏兼容性取决于目标环境。
