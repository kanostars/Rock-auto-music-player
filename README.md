# RockAutoMusicPlay

当前版本：1.0.0

将本地 MIDI 文件转换成固定九音键谱的 Windows 桌面软件，支持手碟采样试听与通过 Interception 驱动自动按键弹奏。

使用 C++20 + Qt 6 Widgets 实现集转换、编辑、试听和自动演奏于一体的工作台，使用 Midifile 解析 SMF 文件。

## 运行

直接启动 `build/RockAutoMusicPlay.exe`，需要保留同目录 DLL 和 `platforms` 等插件目录。可将 MIDI 文件拖入窗口，或点击右上角“导入 MIDI”。使用 `samples/studio-demo.mid` 可体验多轨、变速和近似音转换。

1. 导入后自动按九个目标音转换，并在时间轴显示。有同键过密冲突时弹窗选择“跳过冲突音符”“删除冲突音符”或“保留”；批量导入时选择统一应用到本批有冲突的曲目，无冲突曲目不受影响。默认与关闭弹窗均为保留。
2. 左侧勾选音轨参与转换，独奏只保留启用的独奏轨。
3. 右侧默认“自动移调适配”，在 −12～+12 半音中推荐整体移调，再逐音优先保留同音名、折叠到可用八度；没有同音名的音符才“转换成最近音 / 直接跳过”。点击“应用设置 · 重新转换”生效。“不整体移调”固定移调为 0，仍保留同音名八度折叠。
4. 选择“全部音轨”或单轨只改变显示范围，不改变转换统计。
5. 滚轮横向移动，Ctrl + 滚轮缩放；“查看全部”适配整首曲目。
6. 点击音符查看原音、目标音、按键、时间和力度；“转换报告”按开始时间分页显示全部转换记录（含准确映射，每页 200 条），支持首页、上一页、下一页、末页及输入页码跳转，双击记录定位音符。
7. 底部统一提供“手碟试听”“开始演奏”“停止”、共享时间、上一首/下一首、音量和转换报告。中间只有一套可编辑音符轨道；试听和自动演奏使用同一歌曲位置与已应用的 BPM、倍率、按下时长和松开间隔，输出方式切换时先停止旧输出。“停止”终止两种输出并回到开头。
8. 点击“全屏轨道”在独立窗口放大音符区，保留音轨筛选、缩放、添加、框选、移动、拉伸、音高调整、删除、撤销/重做，以及完整试听和转换报告。F11 切换全屏/普通窗口；“返回主界面”或关闭独立窗口会将轨道放回原位，保留选择、编辑记录和播放进度。Esc 仍用于取消编辑；播放时先暂停再编辑。主界面仍可切换曲目和应用转换设置。

导入冲突处理会按时间保留每个按键较早的敲击，再与上一次保留的敲击比较，只处理不足“按下时长 + 松开后间隔”的后续音符。同 tick 同键照常合并，不误判为冲突；不同按键的和弦不受影响。“跳过”保留音符在已跳过行及转换报告中，但不参与试听、自动演奏和 MIDI 导出；“删除”隐藏音符并计入删除数。两种处理都只作用于当前会话，不改写原文件，每首曲目可分别撤销 / 重做，重新应用转换设置后仍保留处理结果。“保留”继续显示冲突，仍需解决后才能试听或自动演奏。

## 导出 MIDI

点击音符工具栏中“重做”右侧的“导出 MIDI”，选择路径即可保存当前曲目的完整九键谱，默认文件名为“原曲名_九键.mid”。如果修改了转换参数，请先应用设置；自动演奏期间导出按钮暂不可用，试听中导出会先暂停试听。

- 导出标准 SMF Format 0 MIDI，保留原 PPQ、音符力度、已编辑的音高与时长，以及新增音符；跳过、删除和未参与转换的音轨音符不会写入。显示筛选和当前播放位置不限制导出范围。
- 同 tick 同键音符按最长时长、最大力度合并，与试听一致；不同时间的同音重叠使用独立旋律通道，避免提前松键。原来的多音轨来源合并成九键谱。
- 跟随原曲时保留变速点，固定 BPM 时写入固定速度；播放倍率折算进 MIDI 速度。按下时长、松开间隔和倒计时属于按键演奏参数，不会替代音符条时长。
- 导出的是音符数据，不包含内置手碟 WAV 音色；其他 MIDI 播放器的音色取决于其音源。重新导入本软件后仍可用手碟采样试听，编辑历史和播放列表不随文件保存。
- 支持中文路径、补全 `.mid` 后缀和覆盖确认；保存失败会提示，采用原子写入避免留下半个文件。

## 手碟试听

工作台保留左侧曲目与音轨、中间音符编辑、右侧设置的三栏布局，已移除独立自动演奏页面及重复的歌曲信息、只读轨道和参数。左侧曲目库下方的一行图标分别为上移、下移、删除和播放模式；悬停可查看说明。点击播放模式图标在单曲播放（结束后停止）、顺序播放、单曲循环和随机播放之间切换，图标显示当前模式，试听与自动演奏共用。可用上移 / 下移箭头排序，“删除”仅移出曲目库并清除该曲目的会话编辑，不删除磁盘 MIDI 文件。排序保留转换设置、编辑和撤销记录；删除当前曲目后选中相邻曲目，全部删除后清空轨道，仍可继续导入。

播放模式默认为“单曲播放（结束后停止）”：放完当前歌曲后停止，不自动换曲。“顺序播放”在当前歌曲结束后衔接下一首，列表末尾回到第一首；“单曲循环”重复当前歌曲；“随机播放”打乱其余曲目连续播放，存在多首时不会紧接着重复同一首。仅有一首时，除单曲播放结束停止外，其余三种模式均循环当前歌曲。时间右侧的“上一首 / 下一首”可切歌，上一首优先回到已播放历史，随机模式的下一首沿随机队列前进；其他模式手动切换按列表顺序，在列表两端循环。

手碟试听会等当前歌曲余音结束后按模式切歌，下一首直接从头试听，不使用演奏倒计时，也无需键盘或目标窗口。试听中可切换播放模式，点击上一首/下一首会切歌并继续试听；暂停或停止时点击只切歌。暂停保留当前位置和播放队列；停止、手动点选曲目、删除或排序会取消连续试听。下一首有同键冲突、没有可播放音符或音频设备出错时停止衔接。

自动演奏每首开始前均使用设定的倒计时；连续切歌使用新歌曲已应用的转换和节奏参数，沿用输出键盘、目标窗口和倒计时设置。下一首从该曲目的区间起点开始并重新检查冲突和设备状态，失败时停止连续演奏并提示。暂停保留当前位置；停止、快捷键终止、手动选曲、删除或排序都会停止连续演奏并释放按键。演奏中点击上一首/下一首会切歌后重新倒计时，暂停或停止时点击只切换歌曲。

右侧“转换设置”是唯一的音高、BPM、倍率和按键时长设置来源；“自动演奏”标签提供键盘/窗口选择、测试按键、倒计时与窗口激活选项。底部开始演奏会校验并应用待提交的转换设置，然后从当前轨道位置开始。切换右侧标签不会终止演奏。自动演奏会话期间（含倒计时和暂停）锁定音符编辑及转换参数，终止后恢复；试听暂停后仍可直接编辑。

“刷新键盘”“刷新窗口”仅在点击时各自启动后台查找；启动软件、切换歌曲或设置标签都不会自动扫描。每次刷新清空对应列表和旧选择，下方显示扫描中、找到数量、未找到或错误提示。找到后仍保持选择框为空，需手动选择；刷新一侧不改变另一侧的选择。倒计时最少 1 秒，默认 5 秒，演奏期间不可修改。

“测试按键”打开“九键手碟测试”小窗，按参考图重绘圆形音键、彩色简谱数字和谱线：上排 T/Y/U，中排 F/G/H/J/K，下排 B。键盘按下或鼠标点击音键时高亮并播放内置手碟采样，支持多键和弦；四个采样轮换，长按不自动重复敲击，松开后余音自然衰减。仅当小窗可见、未最小化且获得前台焦点时接受输入；失焦、最小化或关闭会停止发声并清空按键高亮与待播音符，重新聚焦后需再次按键。此小窗使用本地键盘/鼠标输入与扬声器试听，无需选择输出设备，不向其他窗口发送按键。

小窗下方的“按键日志”实时记录成功触发的本地时间（`HH:mm:ss.zzz`）、键盘 / 鼠标、按键、简谱音高、音名和 MIDI 音高编号，支持选择复制和清空，保留最近 1000 条。时间表示本窗口收到触发的时刻，不是音频设备实际发声时刻。长按自动重复、无效按键及失焦或最小化后的输入不会产生记录；失焦保留已有日志，关闭小窗后不保存。

键盘通过 Interception 查找可用键盘通道，保存通道编号与硬件 ID；需要已安装并正常工作的驱动。窗口通过 [EnumWindows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-enumwindows) 查找有标题、可见的顶层窗口，排除本进程、工具窗及被系统隐藏的窗口；列表保存窗口句柄与进程 ID。刷新只读取列表，不激活目标窗口；实际演奏前会重新验证设备和窗口有效性。

- 使用 miniaudio 0.11.23 输出音频；音色来自用户提供的 SiftHandpanWorkbench v0.1.4 内嵌资源，九个按键各 4 个采样，共 36 个原始 WAV，以 44.1 kHz 立体声嵌入程序。无须安装音色库或 Interception 驱动；来源及校验记录见 [采样说明](assets/handpan/README.md)。
- 每个键的采样按时间轴顺序轮换，连续敲击使用不同版本。同 tick 同键合并后只消耗一个版本；暂停、继续及定位保持同一首曲目中的采样选择一致。
- 使用系统默认扬声器/耳机，默认音量 60%，可调到 0 静音。设备打开失败时显示错误并停止游标，不伪装成无声播放。
- 播放转换后的目标键，遵循当前速度、BPM、音轨启用/独奏及手工编辑。显示筛选只控制轨道显示。改变转换或手动点选曲目会暂停试听；音符编辑需先暂停或停止播放。
- 由音频采样时钟调度，支持和弦及重复敲击；同 tick 同键按最长时长/最大力度合为一次敲击。暂停会停止输出，继续或定位从对应采样位置恢复余音；停止回到所选区间起点。
- 保留原始 MIDI 力度的音量差异及采样左右声道；音符结束后约 0.35 秒渐弱，原始采样约 3.70～4.39 秒，不循环拉长。修改音符长度会改变提前释放的位置；改变速度不改变采样音高。试听在所选区间右边界停止，余音不会越过边界。
- 最多同时混合 128 个发声实例（包含余音），超出时替换最早结束的实例；软限幅避免密集和弦发生硬削波。播放缓冲约 10 ms 请求值，实际输出延迟取决于系统设备。
- 工作台试听使用本地采样；向目标窗口发送按键时，在右侧“自动演奏”设置输出设备，再点击底部“开始演奏”。
- 存在同键过密冲突时禁止试听，点击播放会弹窗说明冲突数量和处理方法；不同键的和弦正常播放。调整参数后需先应用并重新转换，消除冲突才能播放。
- 试听期间时间轴进入只读状态：可选择音符查看详情，但不能拖动、拉伸、删除、点选删除、撤销或重做。点击时间轴空白位置会定位并暂停；焦点留在时间轴时，按空格可从当前位置继续，再按一次暂停。

右侧参数有效范围：固定 BPM **20～400**、播放倍率 **0.25～3**、按下时长 **1～1000 ms**、松开后间隔 **0～1000 ms**（含边界）。输入或粘贴越界值后，按回车、离开输入框或应用设置时弹窗提示，并恢复上一个有效值；空值、非数字及毫秒参数的小数同样拒绝。上下箭头保持在范围内；原曲速度模式下固定 BPM 不参与输入校验。

## 时间区间与删除片段

音轨内两侧的绿色边界条默认覆盖完整曲目，直接拖动竖条或顶部手柄调整起止位置，并随音轨缩放和横向滚动定位；Esc 取消拖动。区间外显示灰色遮罩。编辑工具栏右侧依次提供重置、删除片段、创建空片段三个图标按钮，悬停显示说明；重置可恢复整首歌范围。区间独立于音符多选和显示筛选，每首曲目分别保存，并随 BPM / 倍率调整缩放。

- 试听与自动演奏仅触发区间内开始的音符（含左端、不含右端），到右端停止声音或释放按键。当前位置在区间外时从左端开始，暂停后在区间内继续。区间外的同键冲突不阻止播放；空白区间按正常时长播放静音。
- 原有单曲停止、顺序播放、单曲循环、随机播放均以区间末尾为结束点；下一首使用自己的区间，单曲循环返回当前区间起点。
- **创建空片段**：在区间起点插入与所选区间等长的空白，后续音符和变速点整体后移，跨插入点的音符拆成前后两段。变速歌曲也保持所选秒数，插入后绿色边界覆盖新空白。创建可整步撤销 / 重做，不增加曲目，也不改写原 MIDI 文件。
- 点击 **删除片段** 会删除所有音轨中的这段时间，包括空白；区间内音符移除，跨边界音符裁短，后续音符和变速点整体前移，拼接处继承原右边界的速度。即使只显示单轨，也会处理所有轨道。
- 删除后保留两条绿色边界原来的时间位置；超出删减后的曲尾时收回至曲尾，不自动全选。可通过撤销 / 重做恢复时间、音符、速度和区间；删除整个区间可清空曲谱，再添加音符。导出 MIDI 包含删除片段后的完整曲目，单纯框选不裁剪导出内容。原始文件不改写。

## 编辑音符

- **添加音符**：导入 MIDI 后点击“添加音符”，再点击 B～U 九键行的空白位置创建音符，横向位置决定开始时间；默认时长一拍（四分音符）、力度 100，可连续添加。再点按钮或按 Esc 退出添加模式；点击已有音符仍可选中和编辑，不会重复创建。“已跳过”行、标尺和轨道外不能添加。
- **新增音符所属音轨**：显示单轨时添加到该轨；显示全部音轨时，优先使用左侧选中的已启用且符合独奏范围的音轨，否则使用第一个可播放音轨。目标轨静音或不在独奏范围时提示先启用。空 MIDI 第一次添加时自动创建手工音轨。添加模式与点选删除互斥，试听时关闭添加模式并禁用按钮。
- 新音符可参与框选、移动、拉伸、删除、试听和撤销/重做；新增本身独立记为一步。重新转换、调速或切换曲目仍保留，默认一拍时长随实际速度变化。新音符不参与原曲的自动移调估计，始终使用点击指定的九键音高。曲目标题下显示新增数量，左侧音轨音符栏显示“原始 + 新增”。原始 MIDI 文件不被修改；新增与其他编辑一样仅保存在当前会话中。
- **框选 / 多选**：在时间轴空白处按住左键拖动，选中与矩形相交的音符。Ctrl 点击可增减选择，Shift 点击可追加；Ctrl/Shift 拖框可追加选择。Ctrl+A 全选当前显示范围内的音符（含横向滚动之外的音符），更改音轨显示筛选会清空选择。空白处单击仍可定位播放位置。
- **批量移动 / 音高**：拖动任一选中音符的中间，整组左右移动时间、上下移动九键音级；也可按 ↑ / ↓ 升降一个音级。最低 B（A2）、最高 U（E4），组内任一音符到达边界时整组停止，保留相对音级距离。向左移动时以最早音符为边界，不进入负时间。音符所属 MIDI 音轨保持不变。
- **批量调整长短**：拖动任一选中音符的左端，整组起点移动相同秒数并保持各自终点；拖动右端，整组增减相同时长并保持各自起点。缩短时受组内最短音符限制，不缩成零。选中后显示白色手柄；很短的音符会在条外显示手柄，也可先放大时间轴。
- **批量删除**：点击“删除 (数量)”或按 Delete 删除整组，也可右键选择删除。开启“点选删除”后，点击已选组中的音符删除整组，点击其他音符删除该音符。
- **撤销 / 重做**：使用工具栏按钮或 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z。一次批量删除、拖动、拉伸或方向键移调只记为一步，整组一起恢复；每首曲目独立保留最近 256 步历史。
- 拖动过程实时显示预览，松开提交；Esc 取消当前拖动或框选，未拖动时按 Esc 清空选择。试听期间不可编辑，暂停或停止后恢复编辑。时间不能小于 0，时长至少保留 1 个 MIDI tick。
- 手工编辑的音符显示为蓝色。统计、和弦、同键冲突与曲目时长随编辑更新；“已跳过”行中的音符可删除，移动和拉伸只对九键音符开放。
- 修改按原曲 tick 保存在当前会话中；切换曲目、静音音轨、改变近似/跳过策略及重新转换均保留修改。修改速度或 BPM 时，手工编辑的时间也随之变化。原始 MIDI 文件不被改写，关闭程序后编辑记录不保留。

九键音高：B=A2(45)、F=E3(52)、G=F3(53)、H=G3(55)、J=A3(57)、K=B3(59)、T=C4(60)、Y=D4(62)、U=E4(64)。借鉴 SIFT v0.1.6 的同音名优先算法，对参与的原始音轨统一尝试 −12～+12 的每个整数半音：先保留最多同音名音符，再最小化折叠距离总和，再优先移调幅度较小、移调值较低。手工编辑、删除和新增不影响原始音符的估计，手工目标始终优先；静音、独奏改变参与集合时重新计算。

同音名映射包含直接命中和跨八度折叠；折叠数在设置与报告中单独说明。只有没有同音名时才按绝对半音距离近似（等距取低）或跳过。原始 MIDI 与节奏不变，但移调会改变原调、折叠会压缩音域。提取依据、与参考软件的区别及示例见 [音高转换说明](docs/pitch-mapping-v016.md)。

用户提供的《加勒比海盗》回归案例：原曲 241 个音符，E4～E5；整体降低 12 半音后准确映射到 E3～E4，按键序列与用户提供的简化谱逐项核对。案例与键位分布见 [转换说明](docs/pirates-conversion.md)。

自动演奏已接入 Interception；程序不会自动安装驱动。关闭程序后不保存会话。

## 构建

当前机器已将 Qt 6.8.3 MinGW SDK 放入 `.deps/Qt`，使用 CLion 自带的 MinGW 13.1 和 CMake。PowerShell 运行：

```powershell
./scripts/build.ps1
```

其他环境使用 C++20 编译器、CMake >= 3.24、Qt >= 6.5（Widgets / Concurrent）。编译器需与 Qt 二进制工具链匹配：

```text
cmake -S . -B build -DCMAKE_PREFIX_PATH=<Qt SDK 路径> -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Windows 每次链接后由 CMake 自动部署 Qt DLL、MinGW 运行库及 `platforms` 插件，覆盖 `build`、CLion 的 `cmake-build-debug` 以及其他构建目录；不需要修改系统 PATH。Qt SDK 不提交进源码。依赖来源见 [third_party/SOURCES.md](third_party/SOURCES.md)。自动测试源码、CTest 目标、虚拟音频后端和测试专用入口已移除；软件中的“测试按键”窗口与日志功能保留。

CLion 选择 `RockAutoMusicPlay` 目标，重新加载 CMake 后编译运行即可。不要单独移动 EXE；必须保留输出目录中的 DLL 和 `platforms` 文件夹。若旧构建出现 `0xC0000135`，重新构建该目标，让构建步骤补齐运行库。

## 当前范围

- 自动演奏：手动刷新并选择输出键盘、目标窗口，从当前预览位置开始；按设定时间倒计时（默认 5 秒，最少 1 秒），暂停/继续保留剩余倒计时。
- 右侧“自动演奏”设置中的“立即打开目标窗口”勾选后会先恢复最小化窗口，再请求并确认前台焦点；已最大化的窗口保持最大化。未获得焦点会提示手动切换；不勾选时由用户手动切换。目标不在前台时暂停输出。
- 全局快捷键 `Ctrl+Alt+Q` 暂停/继续，`Ctrl+Alt+E` 终止。暂停、终止、切换曲目和关闭程序都会释放演奏按键。快捷键仅在演奏会话期间注册。
- 演奏按原曲速度或固定 BPM 调度，沿用工作台速度倍率；同一时刻的同键合并，和弦同时按下。按下时长与松开间隔超出同键节奏时阻止开始，需调整参数。
- 已通过检查的同键连击若遇到系统调度抖动，会自动等待补足实际松开间隔，并相应顺延后续时间轴；不会将短暂延迟误报为同键冲突而暂停，也不会跳过音符或拆散和弦。
- 输出使用已安装的 Interception 驱动及所选键盘通道。请保留运行目录的 `interception.dll`；驱动未就绪时界面会提示，不会自动安装。第三方来源和许可见 `third_party/interception/README.md`。

- 支持 SMF Format 0/1、PPQ、原曲变速、固定 BPM 和倍率；支持中文文件路径。
- 原始数据保持不变；可切换近似/跳过，显示排除数、和弦数、同键重合及同键过密。
- 导入在后台执行，可取消；每文件上限 32 MB、256 个原始轨道、20 万 Note On、200 万事件。
- 同一原始轨道内按通道拆分显示，通道 10 默认排除，可手动启用。
- 支持点击新增音符、框选与批量移动、拉伸、删除以及撤销/重做。
- 不支持 Format 2、SMPTE、实时 MIDI、弯音/踏板效果、通用 MIDI 乐器音色、音频导出和会话保存。
- 时间轴当前显示秒刻度；小节/拍号网格与全曲缩略图留待后续完善。
- 主窗口使用按可见区域批量绘制的滚动时间轴，避免为每个音符创建独立控件。

方案与后续阶段见 [docs/design-v0.1.md](docs/design-v0.1.md)。
