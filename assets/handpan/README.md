# 手盘采样

当前音色来自用户提供的 SiftHandpanWorkbench v0.1.4，其 `Workbench.Core.dll` 内嵌的 `HandpanSamples.{按键}_{1～4}.wav`。已替换旧视频录音切片，36 个 WAV 均保留原始字节，未经调音、重采样、归一化或裁切。

格式为 PCM WAV、44,100 Hz、16 位、双声道，单个约 3.70～4.39 秒。`manifest.json` 记录源程序 SHA-256，以及每个采样的资源名、大小、SHA-256、帧数和按键映射。

| B | 低6 | A2 / 45 | B_1.wav ～ B_4.wav |
| F | 3 | E3 / 52 | F_1.wav ～ F_4.wav |
| G | 4 | F3 / 53 | G_1.wav ～ G_4.wav |
| H | 5 | G3 / 55 | H_1.wav ～ H_4.wav |
| J | 6 | A3 / 57 | J_1.wav ～ J_4.wav |
| K | 7 | B3 / 59 | K_1.wav ～ K_4.wav |
| T | 高1 | C4 / 60 | T_1.wav ～ T_4.wav |
| Y | 高2 | D4 / 62 | Y_1.wav ～ Y_4.wav |
| U | 高3 | E4 / 64 | U_1.wav ～ U_4.wav |

按键与简谱来自截图，目标 MIDI 沿用本项目原有规则；不是对采样实测基频的声明。

程序通过 Qt 资源系统嵌入这些文件，解码为原采样率的双声道浮点 PCM，逐声道混音。每个键按 1→2→3→4 轮换；同 tick 同键先合并再分配采样。选择由曲目时间顺序决定，因此暂停后重建、继续或定位都能恢复同一个采样的余音。原 SIFT 程序使用随机且避免连续重复的策略，本项目采用固定轮换以保证可重复播放。

原有 MIDI 力度、音量、音符结束后 0.35 秒释放和软限幅规则继续生效，因此程序播放结果会随 MIDI 时长及力度变化。采样文件本身保留完整原音。

自动测试检查全部 36 个内嵌文件与来源哈希一致、原始帧数完整、双声道有效，以及采样轮换、定位恢复、和弦、释放、音频设备和界面播放行为。离线提取/导入方法见 [工具说明](../../tools/audio-extraction/README.md)。正常编译运行不需要源程序或提取工具。

这些采样来自用户提供的软件素材；采样的来源和权利不因 miniaudio 的 MIT-0 许可而改变。
