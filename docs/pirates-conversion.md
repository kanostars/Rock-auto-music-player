# 《加勒比海盗》音域适配案例

输入为用户上传的 `加勒比海盗.mid`，241 个有效音符、1 条音轨，原始音域 E4～E5（MIDI 64～76）。旧规则按绝对音高找最近目标，所有音符都落到最高的 E4 / U，旋律因此消失。

本例整体降低一个八度（−12 半音），得到 E3～E4，全部恰好落在游戏目标音上，不需要近似、不需要跳过，也不需要更改原始节奏。

| 原始音 | 适配后音 | 游戏键 | 数量 |
| --- | --- | --- | ---: |
| E4 / 64 | E3 / 52 | F | 4 |
| F4 / 65 | F3 / 53 | G | 9 |
| G4 / 67 | G3 / 55 | H | 16 |
| A4 / 69 | A3 / 57 | J | 69 |
| B4 / 71 | B3 / 59 | K | 34 |
| C5 / 72 | C4 / 60 | T | 39 |
| D5 / 74 | D4 / 62 | Y | 35 |
| E5 / 76 | E4 / 64 | U | 35 |

U 键由旧规则的 241 个减少为正确的 35 个；B 键在本曲没有对应音符。

回归测试将转换结果按原始开始 tick 排序，与用户提供的 [完整简化键谱](../tests/fixtures/pirates-keys.txt) 去掉空格、换行和等待标记后的按键序列逐项比较。简化谱仅用于核对音高顺序；开始时间、持续时间、速度变化均来自 MIDI，不能从该文本还原。

在软件中重新导入 MIDI，保持“自动八度适配（推荐）”，设置区应显示“整体 −12 半音（−1 八度）”，准确映射 241、近似 0、跳过 0。选择“直接跳过”也应得到同样结果，因为八度适配后的所有音均受支持。

这是本例的正确适配结果，不代表任何 MIDI 都能无损压入九个固定音；宽音域、和声和不支持的半音仍需要近似、跳过或手工调整。
